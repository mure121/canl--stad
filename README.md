# Canlı Stad

TikTok canlı yayını için etkileşimli futbol oyunu. Tek sayfa: `index.html`.

- Yayın paneli: sol üstteki düğme ya da klavyede `P`.
- Canlı bağlantı: yayın bilgisayarında TikFinity açıkken panelden "TikFinity'ye bağlan".
- Lig, puan durumu ve ayarlar tarayıcının yerel hafızasında tutulur.
